# Jedi Task Path

Aplicación web personal para convertir tareas en proyectos de crecimiento.

## Funciones

- Crear proyectos con estado, horizonte, métrica, próximo paso y palanca.
- Cambiar el estado de cada proyecto.
- Calcular el progreso general y el nivel de crecimiento.
- Registrar horas, minutos y segundos invertidos en cada proyecto.
- Generar pasos sugeridos y marcarlos como completados.
- Guardar los datos en el navegador con `localStorage`.
- Diseño responsivo para computador, tableta y celular.

## Uso

Abre `index.html` en un navegador. No requiere instalación, servidor ni base de datos.

## Privacidad

Los datos se guardan localmente en el navegador y no se envían a ningún servidor.
